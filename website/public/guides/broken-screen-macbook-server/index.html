碎屏 MacBook 别扔：合盖改无头服务器完整指南

不用拆屏、不用假 HDMI，一台碎屏或闲置 MacBook 就是一台现成的 24 小时服务器。更新于 2026-10-09。

MacBook 屏幕碎了之后通常只有三条路：官方换屏总成，价格常常接近甚至超过这台老机器的残值；卖二手，碎屏直接砍价到骨头；扔抽屉里吃灰。其实还有第四条：屏幕坏了，不代表机器坏了。CPU、内存、硬盘、Wi-Fi 全都好好的，缺的只是一块显示屏——而服务器恰恰不需要显示屏。

这篇指南讲怎么把一台碎屏（或纯粹闲置）的 MacBook 合盖改造成一台安静、省电、24 小时在线的无头服务器：跑 AI agent、挂下载、做文件服务、跑你自己的小应用都行。办法分手工路线和工具路线两种，都讲，最后给一份注意事项清单。

先说清三件事

  • 不用拆屏。国外有玩家把碎屏整个拆掉做成"无头主机"，但要动排线和天线，风险高、不可逆。合盖 + 软件关闭内屏，效果一样：屏幕不亮、不耗电、不发热，机器保持完整，想变回笔记本随时可以。
  • 首次配置需要一块临时的屏。借任意外接显示器，或者用另一台电脑的「屏幕共享」连进去配一次，之后永远不需要屏幕。
  • 它的定位是服务器。长期插电、合盖、放角落。所以放置通风、电池保护这些细节，后面都会讲到。

准备清单

  • 碎屏或闲置 MacBook 一台（Apple Silicon 或 Intel，系统 macOS 12 或更高）
  • 电源适配器（长期插电用）
  • 一根网线 + 转接头（可选，Wi-Fi 也能跑，有线更稳）
  • 外接显示器一台用于首次配置（或另一台电脑用屏幕共享）

手工路线：能走通，但有四个坑

网上大多数教程是这个路子：外接显示器合盖（clamshell 模式）或者 pmset 命令防休眠，再配个保活小工具。实测下来会依次踩到这四个坑：

  1. 合盖就睡。macOS 的合盖睡眠（clamshell sleep）和闲置睡眠是两套机制，caffeinate、Amphetamine 这类保活工具只管后者。合盖几秒钟，服务全停。
  2. 内屏关不掉。外接屏模式下内屏往往还在亮，或者需要买"假 HDMI 诱骗器"骗系统。不关内屏，碎屏白白耗电发热，还加速老化。
  3. pmset disablesleep 是个裸开关。用管理员命令关掉全局睡眠确实能合盖运行，但它没有电池保护：哪天市电断了、排插被碰掉，机器会一直耗到电量见底，把电池"饿死"。
  4. 远程进不去、出门看不见。SSH、屏幕共享要自己配，出了家门想看一眼服务状态，还得再折腾内网穿透。

四个坑每一个都有解法，但加起来就是一套要长期伺候的组合拳。下面这条路线是把这套拳打包成一个开关。

工具路线：用 MacHead 五步搞定

MacHead 是个免费开源的菜单栏小工具，专门做这件事。整个过程约十分钟：

1. 安装

下载 DMG，把 MacHead 拖进「应用程序」，打开后按提示授予权限。碎屏机器通过外接屏或屏幕共享完成这一步。

2. 一键开启无头模式

点一下菜单栏图标：内屏关闭（碎屏不再亮起、不再发热）、合盖不再休眠、内置键盘和触控板自动锁定防误触、麦克风物理静音——一台 24 小时开着的机器，不该是个开放的麦克风。

3. 打开电池守护和温度告警

电池守护的作用是：意外断电且电量低于安全阈值时，自动恢复正常睡眠，保住电池。温度告警可以推送到 Bark 或 Telegram，机器发烫你会第一时间知道。放置上记住一条：通风的硬桌面，不要放床上、不要塞抽屉。

4. 配远程访问

打开 Web 控制台（首次启动会随机生成管理密码，手机浏览器就能看 CPU、内存、电量，还能远程开关功能）；出门在外要连回来，启用内置的内网穿透——Cloudflare Tunnel、Microsoft Dev Tunnels、FRP 三选一，不用在路由器上开端口。已经在用哪吒监控、ServerStatus、Uptime Kuma 的可以直接接上。

5. 把服务跑起来，合上盖子

该装的服务照常装：AI 编程 agent 让它夜里自己干活、下载任务挂着、文件共享开起来。合上盖子，走人。机器安静地在角落运行，状态随时掏出手机就能看。

碎屏机特别注意

  • 不要拆屏。Wi-Fi 和蓝牙天线在转轴附近，拆屏容易伤到；合盖方案完全不碰硬件，天线、排线都不动。
  • 碎屏有玻璃渣先处理。贴一层膜或把碎裂处贴好再合盖，别让玻璃屑掉进键盘。
  • 铰链松了就别反复开合。配好之后它就是个固定设备，找个角落放稳，平时用远程访问，不需要再打开盖子。
  • 老机器先换块电池再服役（如果已经鼓包）。鼓包电池不适合长期通电，先处理掉这个隐患。

改完能拿它干什么

  • 24 小时 AI agent 主机：合盖跑 Claude Code、Codex 这类 agent，晚上派活、早上收结果，不用再为它开一台云服务器。具体玩法见英文版指南 Turn Your Old MacBook into a 24/7 AI Agent Server。
  • 下载机与文件服务：安静、省电、自带电池防断电，天生适合挂PT、做家庭文件共享。
  • 自托管小服务：博客、监控面板、自动化脚本、软路由旁路——macOS 是完整的 Unix 环境，Docker 和各类运行时都齐全。
  • 开发测试机：一台常年在线的 Mac，跑 CI、做 iOS 构建、远程开发都合适。

常见问题

碎屏不修，真的能当服务器用吗？

可以。屏幕只是输出设备，机器的其他部分不受影响。无头模式下内屏直接关闭、由虚拟显示接管，首次配置借一块外接屏或用屏幕共享完成，之后再也不需要屏幕。

需要把碎屏拆下来吗？

不需要。拆屏要动排线和天线，风险高且不可逆；合盖 + 软件关内屏效果相同，机器保持完整，随时能恢复成笔记本。

合盖长期运行会不会过热？

合盖略微影响散热，放在通风的硬质表面即可。MacHead 有温度告警（Bark / Telegram 推送），日常 agent、下载这类轻负载基本不用担心。

电池会不会被"饿死"？

长期插电有系统级电池健康管理；真正的风险是断电后防休眠把电耗尽。MacHead 的电池守护会在低电量时自动恢复正常睡眠，避免过放。

Intel 的老机器还行吗？

行。Apple Silicon 与 Intel 都支持，系统 macOS 12+。老机器跑云端模型的 agent、下载、文件服务完全够用，只是风扇声和功耗大一些。

和买一台 Mac mini 比呢？

手里的碎屏机器改造成本为零，还自带电池当 UPS；Mac mini 要额外花钱且停电即关机。除非明确需要一台全新主机长期服役，先把手里的机器用起来更划算。
