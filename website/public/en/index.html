Turn your MacBook into a headless server

MacHead is a free, open-source macOS menu-bar app that turns any MacBook — even one with a broken screen — into a quiet headless workstation. Open the lid, it's a laptop. Close it, it's a server.

Download for macOS View on GitHub

Free & open source (Apache-2.0) · Apple Silicon & Intel · macOS 12+

What it does

One-click headless mode

Internal display off, clamshell sleep handled, virtual display when you need a GUI. No dummy HDMI plug, no pmset scripts.

Broken-screen friendly

A cracked or dead internal display is not a problem — headless mode never needs it. Give that MacBook a second life as a server.

Battery & thermal guard

Restores normal sleep at low charge, watches temperature, and auto-mutes the microphone for always-on duty.

Web console & CLI

Monitor CPU, memory, GPU and battery from a LAN web dashboard, or drive everything with the machead command-line tool.

Remote access built in

Reach your headless MacBook from anywhere via Cloudflare Tunnel, Microsoft Dev Tunnels or FRP — no port forwarding.

Made for 24/7 agents & homelabs

Keep AI coding agents (Claude Code, Codex) running with the lid closed, or run a silent home server on a spare MacBook instead of buying a VPS.

Who it's for

AI agent runners

Long agent sessions die when the lid closes. MacHead keeps the machine awake, reachable and guarded overnight.

Homelab & self-hosters

A spare MacBook is a low-power, UPS-backed (its own battery) server with a real Unix under the hood.

Owners of broken MacBooks

Screen repair can cost more than the machine is worth. As a headless server, it can serve for years.

FAQ

Can I run MacHead on a MacBook with a broken screen?

Yes. Headless mode turns off the internal display and works with a virtual display, so a cracked or dead screen does not matter. You can do the one-time setup with an external monitor or via Screen Sharing.

Will a closed MacBook overheat or drain its battery as a server?

MacHead includes a battery guard that restores normal sleep at low charge, plus temperature alerts. For 24/7 use, keep it plugged in on a hard, ventilated surface.

Does MacHead work on Intel Macs?

Yes. MacHead supports both Apple Silicon and Intel MacBooks, on macOS 12 or later.

How is MacHead different from Amphetamine or caffeinate?

Those mainly block idle sleep; clamshell (lid-closed) sleep needs extra handling, and they leave the display and setup work to you. MacHead is a complete headless workstation mode: display off, lid-closed operation, web console, CLI and remote access in one app.

Is MacHead free?

Yes — free and open source under the Apache-2.0 license.
