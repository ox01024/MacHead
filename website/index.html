MacBook 合盖服务器
优雅重塑，极致冷静。

MacHead 是一款轻量、零依赖的开源原生工具。它通过私有 SkyLight API 从逻辑上切断内置屏幕信号，完美实现合盖运行。无需担心发热损坏屏幕，伴随智能电量断电保护与隐私锁，让您的旧 MacBook 获得第二次生命。

重写软硬件边界的底层守护

MacHead 专为持久化合盖运行设计，用逻辑链封锁功耗与发热风险。

内屏信号逻辑切断 (SkyLight Private API)

不同于第三方简单的显示镜像，MacHead 通过直接挂起并阻断 macOS 私有 SkyLight 驱动层信号，实现内屏背光的物理全熄。合盖运行时，内屏屏幕不通电、零发热，完全杜绝因排线受热加速老化甚至屏幕开胶的硬件惨剧。

硬件防窃听隐私锁

只要笔记本进入 Headless 无头模式，MacHead 会在硬件音频控制器层面自动将系统默认麦克风输入全链路静音。即使服务器遭到网络攻破，外部程序也绝无可能通过麦克风监听物理空间的声音，实现军工级的隐私物理防护。

电池健康与低电量断电守护

针对长期处于插电服务器环境的 MacBook，MacHead 智能劫持电量阈值。一旦拔掉充电线，在电池容量耗至安全限额（如 20%）时，它会自动清除唤醒断言并诱导系统进入深度休眠，彻底避免锂电池过度放电损坏造成的电池鼓包。

输入设备物理隔离与防误触

合盖成为服务器后，压在屏幕上的物理按键极其容易被误触。MacHead 在 IOKit 驱动捕获层直接进行 EventTap 拦截，进入无头模式时，自动独占并物理忽略内置键盘、触控板的全部输入事件；同时在检测到外接鼠标接入时可彻底禁用内置触控板。

局域网轻量 Web 面板

应用内置超轻量级、完全无依赖的 Swift 异步 Web 服务。您可以在同局域网的手机、电脑浏览器上远程登录它，查看实时的 CPU 负载、物理内存占比、电池容量、充电状态与插电方式，并且直接远程一键开/关 Headless 模式。

外接屏智能双向插拔守护

为了防止屏幕彻底黑屏而遭遇“被锁死在外”的窘境，MacHead 全时段监测外接显示器的物理连接：当意外断开所有外接屏时，防黑屏保护逻辑会自动重连并亮起内屏；而再次将屏幕连回时，它能秒级自动恢复无头断电保护。
